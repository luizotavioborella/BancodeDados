# 🗄️ Database Activities

A collection of database exercises developed with SQL and Firebird.

These activities were created during the Systems Development course at SENAI to practice database creation, table relationships, data manipulation and SQL commands.

## ✨ Features

- Database and table creation
- Data insertion
- Data updating
- Data deletion
- Table structure modification
- Primary keys
- Foreign keys
- Relationships between tables
- Data filtering
- Result ordering

## 🐾 Veterinary Database

The repository includes the structure of a veterinary clinic database with tables for:

- Tutors
- Patients
- Veterinarians
- Appointments
- Prescriptions
- Prescription items

The tables are connected through primary and foreign keys to represent relationships between the clinic's data.
